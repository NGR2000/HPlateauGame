# 開発・実験（ローカル専用）

このディレクトリは公開サイトの生成対象から除外します。通常版のURLに `dev`、`city`、`road` を指定しても、このコードには切り替わりません。

リポジトリルートで `npm ci` と `npm run build` を実行してローカル用の Three.js を用意し、`python3 -m http.server 8000 --bind 127.0.0.1` で配信します。ローカルブラウザで `/game/development/play.html` を開くと開発版のエリア選択から始まります。`?setup=1` では従来のブリーフィング、`?dev=1&city=1` ではPLATEAU、`?dev=1&road=1` では道路と地上クルーを確認できます。

気象APIは Open-Meteo、地形・写真・地図・道路は国土地理院、建物はPLATEAUを使用します。必要な接続先が環境で許可されている場合のみ取得できます。TLS検証を無効化したり、接続制限を回避したりしないでください。

住所検索とその専用処理は開発版からも削除しています。共有URLと風入力には通常版と同じ制限を適用し、気象レスポンスは形式・値・件数・容量・取得時間を検証します。開始時刻による風の変化は、従来どおり参考判定の表示であり実際の飛行には反映しません。

この分離はデプロイ成果物の範囲を制御します。公開Gitリポジトリに保存されたソース自体を非公開にするものではありません。
