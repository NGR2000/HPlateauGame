# 実際のデータと創作の世界

このプロジェクトでは、実際の地形を土台にした「創作の世界」を中心に開発します。
車で走る・気球から眺める体験から始め、建物を置いて街をつくる遊びへ育てます。
ゲーム名は未定です。

## 遊ぶ

[ホームを開く](https://ngr2000.github.io/HPlateauGame/)

- **実際のデータの世界**：これまでの気球ゲーム。エリア選択、本格モード、実験機能はゲーム内から利用できます。
- **創作の世界**：佐賀・嘉瀬川の既定エリア・風・出発地点を使うチェイスモード。車を操作し、自分のチームを含めた6機の気球が自動飛行します。

創作側は実地形から始める架空の世界です。これから配置する建物は実在の再現を保証しません。
現段階は世界の入口を分けた段階で、建築の配置・編集・保存はまだ実装していません。
最初は離陸地点とターゲット周辺を作り込む想定です。地形の読み込み範囲や移動範囲の制限は追加していません。

車の操作：W/S または上下キーで加減速、A/D または左右キーでハンドル、Vで視点切替、Bで気球と車を俯瞰します。
創作側は自分のチームの離陸地点にある車の視点から始まります。自分の気球は地上から自動で離陸し、ほかの5機は上空を飛びます。
Bキーまたは「6機を見渡す」ボタンで全体を見渡せます。「車の視点へ」ボタンまたはVキーで車の視点へ戻れます。
チェイスモードのバーナー・排気音は車との距離（高度差を含む）で小さくなり、300m以上では聞こえません。創作側は他チームの気球も対象です。俯瞰に切り替えても、音を聞く位置は車のままです。
スマホ・タブレットでは、両方の世界のチェイスモードに前進・ブレーキ／後退・左右ハンドルのタッチボタンが表示されます。前進とハンドルは同時に長押しできます。指を離すと入力が解除され、アクセルを離した車は自然減速します。
景色を広く見せるため、普段は左右下の半透明の運転ボタンと右上の「☰ メニュー」だけを表示します。視点・俯瞰・一時停止・計器・世界名・ホームへの移動はメニュー内にまとめています。視点を選ぶとメニューは自動で閉じます。

創作側の1号車には、提供されたBlenderモデル `sky_chase_car.blend` を使用します。
自分のチームの気球は提供モデル `MV56b_hot_air_balloon.blend` と水色の小さな「気球」の札で識別できます。自分の車にも黄色の「車」の札が付きます。名札はスマホ・PCや視点の距離によらず一定の小さいサイズで表示します。
ほかの5機は色と巡航高度を変えています。回収・スコアの対象は従来どおり自分のチームのマーカーです。
一時停止と時間加速は全機に反映します。
元データとブラウザ用GLB、再変換手順は [車両アセット](game/prototype/assets/README.md) に保存しています。

## クラウドで開発

リポジトリのルートで以下を実行します。ビルドやパッケージのインストールは不要です。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザ確認用の入口は `/game/prototype/` です。

| パス | 内容 |
| --- | --- |
| `/` | ホームへ移動 |
| `/game/prototype/` | 世界を選ぶホーム |
| `/game/prototype/play.html` | 実際のデータの世界 |
| `/game/prototype/play.html?world=creative&mode=chase` | 創作の世界 |

以前の `/game/prototype/?a=…&w=…` などの共有URLは、パラメータを保って `play.html` へ移動します。
創作側は舞台を固定するため、他のエリア・風・モード指定を引き継ぎません。

Three.jsはjsDelivr、地形・航空写真は国土地理院から取得します。PLATEAUや気象などの出典はゲーム内に表示しています。
修正後はホームの両方の入口、ゲーム起動、創作側の車の操作、ホームへの復帰、従来の共有URLを確認してからGitHubへ反映します。
GitHub Pagesは `main` のリポジトリルートから公開します。
